# Digital Logic Adder and Subtractor

An academic digital logic design project developed using CEDAR Logic Simulator.

The project implements 8-bit binary addition and subtraction circuits using basic logic gates and combinational circuit design principles.

## Features

* 8-bit binary adder circuit
* 8-bit binary subtractor circuit
* Logic gate-based implementation
* Carry and borrow operations
* Combinational circuit design
* Digital arithmetic operations

## Technologies

* Digital Logic Design
* CEDAR Logic Simulator
* Combinational Circuits
* Binary Arithmetic

## Components Used

* AND Gates
* OR Gates
* XOR Gates
* NOT Gates

## Functionalities

* Binary addition operations
* Binary subtraction operations
* Carry propagation logic
* Borrow logic implementation

## Purpose of the Project

This project was developed to improve digital logic design, combinational circuit analysis, and binary arithmetic implementation skills.
